## OpenCam 1.0.0

Primera versión estable de OpenCam: usa la cámara de tu móvil Android o iPhone como webcam del PC, por Wi-Fi o por cable, con la conexión cifrada.

### Novedades

**Interfaz nueva en las tres apps**, con un tema claro lila común:

- **Escritorio (Windows y Linux):** barra lateral con Inicio, Dispositivos, Ajustes y Acerca de. En Inicio tienes la vista previa con la resolución, los fps y la latencia encima, un botón para cambiar entre cámara trasera y frontal, la tarjeta de conexión (Auto, Wi-Fi, USB o IP manual) con el código de emparejamiento siempre a mano, ajustes rápidos (resolución, fps, cámara, voltear imagen y estabilización) y los ajustes avanzados plegables (zoom, calidad y reconexión).
- **Android:** navegación lateral (Inicio, Conexión, Ajustes), estado del servidor, tarjeta de la cámara (toca para cambiar entre trasera y frontal), dirección del servidor con botón de copiar, código de emparejamiento grande y ajustes rápidos. La app estrena icono.
- **iPhone:** pestañas Inicio, Conexión y Ajustes, con vista previa de lo que recibe el PC, dirección con botón de copiar, código de emparejamiento y ajustes rápidos.

**Cámara virtual de Windows compatible con más apps:** se registra igual que la de OBS e incluye una versión de 32 bits, así que ahora la ven Discord y otras apps que antes no la encontraban.

**Android:** el código de emparejamiento está siempre a la vista, también con el PC ya conectado (para emparejar otro ordenador).

### Descargas

| Archivo | Para qué sirve |
| --- | --- |
| `opencam-setup-windows-x86_64.exe` | Instalador de Windows (app + cámara virtual). **Recomendado en Windows.** |
| `opencam-android.apk` | App para el móvil Android. |
| `opencam-desktop-linux-x86_64` | App de escritorio para Linux (cámara virtual con v4l2loopback). |
| `opencam-desktop-windows-x86_64.exe` | App de Windows suelta, sin instalador. |
| `opencam-vcam-windows-x86_64.dll`, `opencam-vcam-windows-x86.dll` | Cámara virtual de Windows suelta (64 y 32 bits), para instalarla a mano. |
| `opencam-desktop-macos-arm64-sin-camara-virtual-solo-y4m` | macOS (Apple Silicon): de momento sin cámara virtual. |
| `SHA256SUMS` | Sumas para comprobar las descargas: `sha256sum -c SHA256SUMS`. |

### Cómo empezar

1. Instala la app en el móvil y el programa en el PC.
2. En el móvil pulsa **Iniciar servidor**; aparece un código de 6 dígitos.
3. En el PC pulsa **Conectar** y escribe ese código la primera vez. Después se conectan solos.

### Actualizar desde la 0.2.x

Actualiza el móvil y el PC a la vez. Los emparejamientos guardados se mantienen.

### Limitaciones conocidas

- macOS todavía no tiene cámara virtual de OpenCam (solo vista previa o grabación a archivo).
- En Linux hace falta el módulo v4l2loopback para la cámara virtual.
- La app de Android funciona en horizontal, que es como la imagen llega derecha al PC.
- La app de iPhone no se publica compilada (hace falta firmarla con una cuenta de Apple).
